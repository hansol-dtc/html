제 첫 웹페이지입니다

body에 쓴 것만 화면에 나온다. 여기서 처음으로 뭔가 보인다.

1. 정리

  • <!doctype html> — HTML 문서라는 선언. 맨 첫 줄
  • <head> — 화면에 안 보이는 정보. 제목, 문자 인코딩
  • <body> — 화면에 보이는 내용

한글이 깨지면 십중팔구 <meta charset="utf-8">가 없는 것

charset 빠뜨려서 한글 깨지는 사고가 매년 나온다. 미리 못 박아둘 것.

중요한 문단

둘 중 어느 쪽이 맞을까요?

나중에 연 태그를 먼저 닫는다. 괄호와 같은 규칙이다.

2. 정리

  • <태그>내용</태그> — 감싸서 의미를 부여
  • <태그 속성="값"> — 속성은 여는 태그 안에
  • <img>, <br> — 닫는 태그가 없는 빈 태그
  • 나중에 연 태그를 먼저 닫는다

3-1. 정리

  • <h1> ~ <h6> — 제목. h1은 페이지에 하나만
  • <p> — 문단
  • <br> — 줄바꿈, <hr> — 구분선

3-2. 목록

여러 항목을 나열하려면

3-2. 목록 순서 없음

            
              <ul>
                <li>사과</li>
                <li>바나나</li>
                <li>포도</li>
              </ul>
  • 사과
  • 바나나
  • 포도
ul = unordered list. 순서가 중요하지 않은 목록.

3-2. 목록 순서 있음

            
              <ol>
                <li>재료를 준비한다</li>
                <li>물을 끓인다</li>
                <li>면을 넣는다</li>
              </ol>
  1. 재료를 준비한다
  2. 물을 끓인다
  3. 면을 넣는다
ol = ordered list. 번호는 브라우저가 알아서 매긴다. 직접 1. 2. 를 타이핑하지 않는다.

3-2. 목록 중첩

            
              <ul>
                <li>과일
                  <ul>
                    <li>사과</li>
                    <li>바나나</li>
                  </ul>
                </li>
                <li>채소</li>
              </ul>
  • 과일
    • 사과
    • 바나나
  • 채소
안쪽 ul은 li 안에 들어간다. 이걸 틀리는 경우가 많다.

3-2. 정리

  • <ul> — 순서 없는 목록 (점)
  • <ol> — 순서 있는 목록 (번호)
  • <li> — 항목. 항상 ul이나 ol 안에

소개 페이지
메일 보내기

3-3. 정리

  • <a href="주소">글자</a>
  • target="_blank" — 새 탭에서 열기
  • 주소 자리에는 웹주소도, 같은 폴더의 파일 이름도 들어간다

3-4. 이미지

그림을 넣으려면

3-4. 이미지

            
              <img src="html5-logo.svg" alt="HTML5 로고">
img는 닫는 태그가 없다. src에 파일 경로를 넣는다.

3-4. 이미지 크기

            
              <img src="html5-logo.svg"
                   alt="HTML5 로고"
                   width="200">
width만 주면 비율은 알아서 유지된다. 정교한 크기 조정은 CSS에서.

3-4. 이미지 alt

            
              <!-- 그림을 못 불러오면? -->
              <img src="없는파일.png"
                   alt="웃고 있는 고양이">

그림 파일이 없으면 화면에 뭐가 나올까요?

alt는 그림을 못 볼 때 대신 읽히는 글. 눈이 불편한 사용자의 스크린리더가 이걸 읽는다. 장식용이 아니면 반드시 쓴다.

3-4. 정리

  • <img src="경로" alt="설명">
  • src — 그림 파일의 위치
  • alt — 그림을 못 볼 때 대신 읽히는 글. 생략하지 말 것

3-5. 표

행과 열로 된 자료를 보여주려면

3-5. 표

            
              <table>
                <tr>
                  <th>이름</th>
                  <th>학과</th>
                </tr>
                <tr>
                  <td>홍길동</td>
                  <td>컴퓨터공학</td>
                </tr>
              </table>
이름학과
홍길동컴퓨터공학
tr = 한 줄(행), th = 제목 칸, td = 일반 칸. 표는 자료를 보여줄 때만 쓴다. 화면 배치용으로 쓰지 않는다.

3-5. 정리

  • <table> — 표 전체
  • <tr> — 한 줄 (table row)
  • <th> — 제목 칸, <td> — 일반 칸

표는 “자료”를 위한 것이지 “배치”를 위한 것이 아니다

3-6. 입력 폼

사용자에게 무언가를 받으려면

3-6. 입력 폼

            
              <form>
                <label for="name">이름</label>
                <input type="text" id="name">

                <label for="email">이메일</label>
                <input type="email" id="email">

                <button type="submit">보내기</button>
              </form>

label의 for와 input의 id를 같게 맞추면 글자를 눌러도 입력창이 선택된다. 직접 눌러 보여줄 것.

3-6. 입력 폼 type

            
              <input type="text">
              <input type="password">
              <input type="date">
              <input type="checkbox">
              <input type="radio">

type 하나만 바꿔도 완전히 다른 입력창이 된다. date는 브라우저가 달력까지 띄워준다.

3-6. 정리

  • <input type="..."> — type에 따라 모양이 달라진다
  • <label for="id"> — 입력창의 이름표. id와 짝을 맞춘다
  • <button> — 누르는 버튼

3-7. div와 span

특별한 의미 없이 묶기만 하려면

3-7. div와 span

            
              <div>
                <h2>공지사항</h2>
                <p>내일은 휴강입니다</p>
              </div>

공지사항

내일은 휴강입니다

div는 여러 요소를 한 덩어리로 묶는 상자. 줄 전체를 차지한다. 점선은 설명을 위해 그린 것.

3-7. div와 span

            
              <p>여기서 <span>이 부분만</span> 강조</p>

여기서 이 부분만 강조

span은 글 흐름 안에서 일부만 감싼다. 줄을 바꾸지 않는다.

3-7. 정리

  • <div> — 덩어리로 묶는다. 줄 전체를 차지
  • <span> — 글 일부만 묶는다. 줄을 바꾸지 않음
  • 둘 다 의미가 없다. 꾸미려고 묶을 때만 쓴다

  • 검색엔진이 무엇이 본문인지 안다

div 범벅은 나중에 자기가 봐도 못 알아본다. 실무에서 가장 크게 체감되는 부분.
